11. HOOK SCENE RULE (CRITICAL):

* If phase == HOOK:

  * DO NOT explain any concept
  * DO NOT define arithmetic progression
  * Only show confusion, frustration, or curiosity
  * End scene with a question or hint, not an answer

11a. SENSORY SPECIFICITY (HOOK and SETUP scenes):

* Every action in a HOOK or SETUP scene must include one micro-sensory detail that grounds
  the emotion in the body — jaw tension, a hand that won't stay still, the sound of breathing
  changing, a stomach that drops.
* Do NOT open a scene with generic observation ("he looked at" / "she noticed").
* Open with a physical sensation or involuntary reaction.

12. DISCOVERY PACING RULE:

* Discovery must feel gradual, not instant
* Characters should:
  observe → doubt → test → realize
* Avoid immediate correct conclusions

12a. COGNITIVE STRUGGLE (CONFUSION and TWIST scenes):

* Counter-examples and twist scenes must show 2-3 failed attempts before any revelation.
* The character must actively try to apply their current (wrong) understanding, get a
  surprising result, try again with a small adjustment, fail again, then discover the
  correct pattern.
* Never jump straight to revelation after one failure. Earn the breakthrough.

13. DIALOGUE NATURALNESS RULE:

* Avoid perfect or teacher-like dialogue
* Add hesitation, partial thoughts, interruptions
* Use phrases like:
  "wait...", "maybe...", "that means...", "hold on..."

14. EXPLANATION DELAY RULE:

* Do NOT fully explain concepts in early scenes
* Spread explanation across:
  S3 → S6 gradually
* Each scene should reveal only 1 small idea

15. SCENE VARIETY RULE:

* Avoid repeating same structure:
  explanation → confirmation
* Mix:
  confusion scenes
  silent realization moments
  visual thinking (drawing, observing)

16. MICRO-TENSION RULE:

* Each scene must include:

  * a question OR
  * a doubt OR
  * a small problem
* Never allow smooth uninterrupted understanding

17. STRICT HOOK ENFORCEMENT:

* If phase contains "HOOK" (case-insensitive):

  * Absolutely NO explanation allowed
  * If any explanation appears, it is INVALID
  * Scene must end with unresolved curiosity

18. NO EARLY RESOLUTION RULE:

* The first 30-40% of scenes must NOT:

  * fully explain the concept
  * resolve the main idea
* If resolved too early → regenerate internally

19. CONCEPT NAMING (CRITICAL):

* Every concept listed in [LS_CONCEPTS] must be explicitly NAMED in dialogue at least once
  across the scene sequence — spoken aloud by a character using the exact term.
* Showing the pattern is not enough. A character must say the name:
  "This is called an arithmetic progression" / "That's the common difference."
* If a concept is in the list and hasn't been named yet in [STORY_SUMMARY], this scene
  must name it.

20. VISUAL ARTIFACT (REFLECTION scenes):

* In REFLECTION scenes, the whiteboard, notebook, sketch, or diagram must be the PRIMARY
  carrier of the insight.
* Describe the artifact in detail first — what is drawn, written, or arranged.
* Dialogue should only annotate what the viewer already sees on the artifact.
* Never let dialogue carry the full insight while the artifact remains vague or decorative.
